# Personal Web Portfolio

## Author
Kevin Dacanay

## Description
This is a personal portfolio website designed to showcase software engineering class projects and personal development work. The site serves as a central hub for viewing project details, status updates, and links to live demonstrations or source code.

## Credits
All work for this project is original. It was built using HTML and CSS following responsive design principles and modern web development practices.

## Instructions for Compiling and Executing

### Running Locally
This application consists of static HTML, CSS, and JavaScript files. No compilation is required to run the project locally.

1. Clone or download the repository to your local machine.
2. Navigate to the project directory.
3. Open the index.html file in any modern web browser (Chrome, Firefox, Edge, Safari).

### Deployment
This project is configured for continuous deployment using Azure Static Web Apps.

1. Changes pushed to the master branch of the GitHub repository automatically trigger a GitHub Actions workflow.
2. The workflow deploys the latest version of the site to the Azure Static Web App instance.

Visit the site @ [https://polite-bush-06b91461e.6.azurestaticapps.net/](https://polite-bush-06b91461e.6.azurestaticapps.net/)
